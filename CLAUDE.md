# Agent Instructions & Project Context

## Project Overview
**Rubixxxlink** is a high-performance Link Management Dashboard built with React 19, TypeScript, Tailwind CSS, Vite, Cloud Firestore, and IndexedDB. It is capable of handling 29,000+ records with 60 FPS performance, offline-first syncing, Bento Grid analytics, and an interactive data table with customizable density, tags, regions, and statuses.
